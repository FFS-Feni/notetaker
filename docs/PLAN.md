## День 1 — 20.10 (вт): каркас, заметки, теги, корзина
**Цель дня: заметку можно создать, отредактировать, удалить в корзину и восстановить в браузере; всё поднимается одной командой.**

3. Теги (≈40 мин)
   - CRUD, цвет, уникальность имени; удаление снимает тег с заметок
   - страница тегов: список, переименование на месте, выбор цвета
4. Заметки без повторов (≈2 ч)

## День 2 — 21.10 (ср): повторы, календарь, живая синхронизация
**Цель дня: две вкладки показывают одно и то же без перезагрузки; календарь с повторами и перетаскиванием.**

1. Повторы (≈2 ч)
   - `services/recurrence.py`: развёртка daily/weekly/monthly с `until`, в поясе серии, 31-е → последний день
   - `occurrence_overrides`: изменить или удалить одно вхождение
   - «начиная с этого дня»: разрез серии
   - `GET /api/occurrences?from&to`
   - юнит-тесты развёртки: границы месяца, `until`, переход на летнее время (пояс Europe/Berlin), разрез серии не трогает прошлое
2. Календарь (≈1,5 ч)
   - FullCalendar: месяц / неделя / день, пояс пользователя, цвет — по первому тегу, неактивные бледные
   - клик → редактор; перетаскивание → перенос (для вхождения серии — только это вхождение)
   - диалог «Только это / Это и следующие / Все» при правке и удалении вхождения
3. Живая синхронизация (≈1,5 ч)
   - `NOTIFY` в транзакциях изменений, `LISTEN` в API, WebSocket `/api/ws` с авторизацией по cookie
   - клиент: переподключение, `invalidateQueries` по событиям, полный перезапрос после переподключения
   - баннер конфликта в открытом редакторе + обработка 409: «их версия / сохранить мою / скопировать мой текст»
4. Тесты: 409 и события по WebSocket (два клиента в pytest)

**Готово, если:** открыл две вкладки → правка в одной сразу видна в календаре и списке другой; одновременная правка показывает баннер, а не теряет текст.

## День 3 — 22.10 (чт): напоминания, письма, «Ближайшее», настройки
**Цель дня: напоминание приходит письмом и всплывает во всех вкладках ровно один раз; все правила из задания про напоминания работают.**

2. Всплывающие уведомления (≈1 ч)
   - `notifications`, событие по WebSocket, отметка `shown`, показ непоказанных при открытии, центр уведомлений («колокольчик»)
3. «Ближайшее» (≈1 ч)

5. Корзина: worker удаляет насовсем через 30 дней; в интерфейсе «удалится через N дней»
6. `scripts/demo_reminder.py`: заметка через 10 мин 30 с с напоминанием «за 10 минут» → через 30 секунд письмо в Mailpit и всплывающее уведомление

## Если не успеваем — что режем (по порядку)
1. GitHub Actions (тесты всё равно запускаются локально `make test`)
2. Регистрация через интерфейс (останется демо-аккаунт + регистрация через API)
3. Центр уведомлений («колокольчик»), останутся только всплывающие
4. Красота интерфейса

**Не режем никогда:** правила напоминаний, «ровно одно», синхронизацию вкладок, конфликты, тесты на них и честный README.

## Главные риски
| Риск | Что делаем |
|---|---|
| Повторы + исключения + разрез серии съедят больше времени | Делаем первыми во 2-й день, юнит-тесты до интерфейса |

| Утечка личного в экспорт сессии | Отдельная сессия в папке проекта; перед сдачей просмотреть файл |
